# Dot Line releases

## 1.1.1 — 2026-10-04

- Publish the source at [ahmadTorkaman/dot-line](https://github.com/ahmadTorkaman/dot-line) under the MIT license.
- Include the license in browser bundles and downloadable source.
- Document every setting, development, and contributions.
- Add automated test and build checks for contributions.

All visual settings and behavior are unchanged from 1.1.0. Earlier published files keep their original URLs and contents.

## 1.1.0 — 2026-10-04

- Adjust dot radius from 0.12 to 0.47 of the grid spacing.
- Connect adjacent dots vertically or horizontally without bridging missing letter cells.
- Draw solid or outline dots.
- Switch between letters cut out of a dot field and dots forming the letters.
- Try style presets in the website playground and standalone demo; embed code follows the settings.
- Build the downloaded source on any machine without a machine-specific preview directory.

The default appearance and hover behavior stay compatible with 1.0.0. Published 1.0.0 files remain available at their original URLs.

## 1.0.0 — 2026-10-03

Initial release: an editable dot alphabet with hover repulsion, collision separation, spring return, responsive sizing, and reduced-motion support.
